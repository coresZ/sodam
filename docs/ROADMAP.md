# Roadmap

当前仓库已经从骨架阶段进入可用桌面客户端阶段。本文记录已完成能力与下一阶段工作。

## 已完成

- [x] GPUI 主窗口、侧边栏、内容路由、底部播放栏
- [x] Dark / Light / 系统主题；封面主色驱动的全局渐变和强调色
- [x] 配置文件与环境变量补全；音质偏好；语言与主题设置
- [x] 扫码登录、账号信息读取、退出登录
- [x] libresoda 接入：搜索、推荐、听歌模式、歌单、收藏、播放、歌词、元数据
- [x] rodio 播放线程、进度、音量、播放模式、自然播完切歌
- [x] 封面缓存、原图/缩略图分层、失败重试
- [x] 搜索综合 / 歌曲 / 音乐人 / 专辑 / 歌单
- [x] 歌手页、专辑页；歌曲名与歌手名跳转详情页
- [x] 我喜欢的音乐、我的歌单、收藏状态
- [x] 推荐队列、听歌模式队列、探索歌单
- [x] 播放页封面、逐字歌词、队列视图
- [x] 虚拟列表、图片并发池、帧耗时与滚动压测工具
- [x] 中英文界面、系统托盘、关闭到托盘
- [x] Arch Linux ARM64 打包与桌面入口
- [x] Windows 便携版 zip：exe 同级放 `portable.txt` 即切换，配置 / 缓存 / 下载都落在程序目录
- [x] 下载：单曲 / 批量队列、管理面板、独立下载音质与命名模板、封面 / 歌词旁路

## 近期优先级

### 1. 稳定性

- [ ] 拉流失败、签名过期、网络中断的统一恢复体验
- [ ] 队列缓存与账号数据在重启后的可预测恢复
- [ ] 长时间播放的内存 / 文件缓存清理策略
- [ ] 更多离线测试覆盖 queue、搜索详情、设置迁移

### 2. 歌单管理 UI

- [ ] 创建歌单
- [ ] 修改歌单名 / 分类
- [ ] 添加 / 移除歌曲
- [ ] 歌单内排序
- [ ] 删除歌单确认与结果反馈

### 3. 搜索与详情增强

- [ ] 搜索联想词 UI
- [ ] 热搜词 UI
- [ ] 专辑 / 艺人分页加载完善
- [ ] 更多空态、错误态与重试一致性

### 4. 播放体验

- [ ] 播放模式 UI 完整化（当前队列内部状态已支持）
- [ ] 音质标签和签名状态的更清楚提示
- [ ] 歌词滚动微调与逐字动画一致性
- [ ] 队列拖拽排序

### 5. 平台与发布

- [ ] 配置文件版本迁移
- [ ] 干净机器安装测试
- [ ] x86_64 Linux 包验证
- [ ] macOS / Windows 支持评估
- [ ] 自动化 CI（带资源护栏）

### 6. 登录与账号

- [x] MFA / 二次验证流程闭环（2046：libresoda 官方组件桥接 + 自动拉起验证窗口；待真机 2046 场景验收）
- [ ] 登录失败原因分类展示
- [ ] Cookie 过期检测与重新登录引导

### 7. 下载

- [ ] 断点续传（当前暂停 / 取消后从头重下，取决于 CDN 是否稳定支持 Range）
- [x] 播放优先走本地下载文件（2026-10-14：本地音乐 / 已下载两个列表直接播磁盘文件，
      自动下一首也识别本地曲目）
- [x] 本地时长探测（2026-10-15：MP4 走 mvhd 快速解析，其它走 rodio）
- [x] 读旁路封面 / 歌词（2026-10-15：`image/` + `lrc/`，`file://` 伪 URL 复用封面池）
- [x] 元数据匹配（2026-10-15：文件名 → 搜索 → 打分，单条右键 + 批量「补全信息」）
- [ ] 歌单内勾选部分歌曲下载
- [ ] 嵌入封面 / ID3 元数据（需评估 `lofty` 等 crate）—— **明确不做 (a) 方案**，
      仅当需要「文件拷到别的播放器也带信息」时再评估，见 `design-plan.md`
- [ ] 下载完成通知（托盘 / 系统通知）

## 非目标

- 不做公共签名代理。
- 不做绕过会员权益的公共服务。
- 不分发官方客户端二进制或用户凭据。
